# 📊 Streamlit Automated EDA Dashboard

An interactive web app for quick exploratory data analysis using **Streamlit**, **YData Profiling**, and **Sweetviz**.  
Just upload your CSV file and instantly explore key insights, distributions, correlations, and profiling reports.

## 🚀 Features

- 📁 Upload any CSV file
- 📊 Automatic univariate visualizations
- 🧠 Correlation heatmap and box plots
- 📋 YData Profiling report integration
- 🍭 Sweetviz report visualization
- 💡 Easy-to-use Streamlit interface
